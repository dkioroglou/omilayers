# v0.3.0 New features and bugfix Release
This is a bug fix release for various issues discovered after the release v0.2.3. Also new features have been added.

## What's Changed
* NEW FEATURE: more than one tag can be assigned to a layer.
* NEW FEATURE: A set of values can be cross-matched and replaced with values from a given layer.
* NEW FEATURE: Layers names can be viewed in a list.
* NEW FEATURE: drop() method now accepts a list of layers to be dropped.
